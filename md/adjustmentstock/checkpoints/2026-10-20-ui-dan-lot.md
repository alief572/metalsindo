# Checkpoint 2026-10-20 — UI, pilihan lot, dan lebar tabel

Melengkapi checkpoint Qty/berat 2026-10-19. Tidak ada perubahan skema, data permanen lokal/live, registrasi menu atau dependency baru.

## Perubahan akhir
- Pilihan lot tidak lagi menyembunyikan baris Qty nol/nonaktif. Semua lot bernomor ditampilkan dengan status; lot tidak valid tidak dapat dipilih. Empty state bertahan setelah perpindahan jenis adjustment dan tombol simpan mengikuti ketersediaan lot.
- Halaman daftar memakai label Indonesia, search hints, format angka lokal, tombol Adjustment berlabel, angka rata kanan, serta tabel yang memenuhi lebar panel.
- Form mempertahankan input Qty/kg independen, dengan pengelompokan jenis/lokasi, input perubahan, alasan, dan tabel saldo awal/akhir/tujuan. Payload dan validasi stok tidak berubah karena penyempurnaan tampilan.
- CSS scoped menyesuaikan desktop/laptop/mobile, kontras AA dan target 44px. Footer Batal/Simpan tetap terlihat saat form digulir. Escape menutup dropdown Select2 tanpa ikut menutup modal.
- Perbaikan tabel DataTables 1.10.7: min-width 100% untuk body table, header inner dan header table mencegah lebar terkunci saat tab diinisialisasi tersembunyi. Scroll horizontal tetap berada di dalam panel pada layar kecil.

## Verifikasi dan cara menjalankan
- PHP lint pada seluruh PHP yang berubah, adjustmentstock_balance.php, adjustmentstock_controller.php dan render PHP/inline JS.
- adjustmentstock_transactions.php memakai temporary tables InnoDB berskema identik di metalsindo_dev: saldo, metadata, booking, validasi, mutasi, rollback, advisory locks dan visibilitas lot legacy.
- node tests/regression/adjustmentstock_ui.js memeriksa perhitungan preview, berat manual, nol, format angka, mode dan status ketersediaan.
- adjustmentstock_lot_dom.js memakai Playwright terisolasi, jQuery/Select2 lokal dan fixture sintetis. Tidak mengakses aplikasi atau database.
- adjustmentstock_page_dom.js menerima JSON dari php tests/regression/adjustmentstock_render.php --fixtures melalui stdin. Memakai Bootstrap/DataTables/Select2 lokal; semua request selain domain fixture yang di-fulfill diblokir. Memeriksa search, payload, Batal, keyboard, preview dan kontrol 44px.
- Regresi layout mengukur kedua tab pada lebar 1920/1440/1280/390px: tabel minimal selebar panel, batas setiap kolom header/isi sejajar (toleransi 2px), tidak ada overflow halaman, dan tombol simpan tetap di viewport.
- Untuk menjalankan tes DOM, pasang paket playwright pada runtime pengujian atau berikan path modul sebagai argumen pertama skrip. Argumen berikutnya opsional adalah channel browser (contoh msedge); page DOM dapat menerima direktori screenshot sebagai argumen ketiga.

## Batasan
- Data produksi dan integrasi dengan tema global pada halaman live tidak diuji. Browser menggunakan fixture dari render PHP dan aset lokal.
- Batas presisi dua desimal, penolakan saldo gudang ganda/NULL, dan guard booking tetap seperti SPEC; tidak ada koreksi data otomatis.
- Perubahan lain di workspace di luar adjustmentstock tidak termasuk scope commit/push ini.
